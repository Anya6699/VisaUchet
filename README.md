# ИС «ВизаУчет» – учет заявок на получение визы

Лабораторная работа № 9 «Кодирование программного продукта». Подсистема учета статусов заявок и журнала выданных виз (формы Ф1–Ф5).

## Технологии

- C# 12, .NET 8, Windows Forms (формы создаются кодом, без дизайнера);
- Microsoft SQL Server 2022 Express, доступ через Microsoft.Data.SqlClient, только параметризованные запросы;
- xUnit – модульные тесты;
- коды государств – ISO 3166-1 alpha-3, валют – ISO 4217, имена – латиницей по ICAO Doc 9303.

## Структура

| Каталог | Назначение |
|---|---|
| `src/VisaUchet.Domain` | сущности, правила статусов, проверки форм Ф1 и Ф2, хеширование паролей |
| `src/VisaUchet.Application` | сервисы регистрации, смены статуса, журнала, отчета, входа; интерфейсы хранилища |
| `src/VisaUchet.Infrastructure` | репозитории ADO.NET (SQL Server), журнал работы, настройки |
| `src/VisaUchet.WinForms` | пользовательский интерфейс, точка сборки зависимостей |
| `tests/VisaUchet.Tests` | модульные тесты xUnit |
| `database` | скрипты создания и заполнения базы данных |

## Установка

1. Установить .NET 8 SDK и SQL Server 2022 Express (экземпляр `SQLEXPRESS`) с утилитой `sqlcmd`.
2. Создать базу данных и заполнить демонстрационными данными:

   ```
   cd database
   sqlcmd -S .\SQLEXPRESS -E -f 65001 -i 01_create_schema.sql
   sqlcmd -S .\SQLEXPRESS -E -f 65001 -i 02_seed.sql
   ```

3. При другом имени сервера изменить строку подключения в `src/VisaUchet.WinForms/appsettings.json`.
4. Собрать и запустить:

   ```
   dotnet build VisaUchet.sln
   dotnet run --project src/VisaUchet.WinForms
   ```

   Или открыть `VisaUchet.sln` в Visual Studio 2022 и запустить проект `VisaUchet.WinForms`.

5. Тесты: `dotnet test tests/VisaUchet.Tests`.

## Демонстрационные учетные записи

| Логин | Роль | Пароль |
|---|---|---|
| `operator` | Оператор приема | `Oper#2026` |
| `consul` | Консульское должностное лицо | `Consul#2026` |
| `head` | Руководитель | `Head#2026` |
| `admin` | Администратор | `Admin#2026` |

Пароли предназначены только для проверки работы. Перед реальным использованием создайте новые учетные записи через администратора и заблокируйте демонстрационные. В базе хранятся только хеши PBKDF2, в журнал `logs/visauchet.log` пароли и персональные данные не записываются.
